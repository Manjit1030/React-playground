# React Counter App

A beginner-friendly counter application built with React and Vite.

## What It Does

The app displays a large counter value that starts at `0`. You can increase the value, decrease it, or reset it back to zero.

## Technologies Used

- React.js
- Vite
- JavaScript and JSX
- CSS
- npm

## React Concepts Used

- Components
- Props
- Event handlers
- The `useState` hook
- Component rendering when state changes

## Install Dependencies

```bash
npm install
```

## Run The Project

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Build The Project

```bash
npm run build
```

## Check Code Quality

```bash
npm run lint
```

## Available Buttons

- **Increment** increases the count by `1`.
- **Decrement** decreases the count by `1`.
- **Reset** returns the count to `0`.
